# Pairing controllers

YUCCA uses one controller at a time. Pair the controller first, then the console. Both are remembered across reboots.

| Controller | Pairing mode |
| --- | --- |
| DualSense / DualShock 4 | Hold **Create/Share + PS** until the light bar flashes |
| DualShock 3 | Needs a one-time USB step to learn YUCCA's address (sixaxis pairing tool); then press **PS** |
| Switch Pro | Hold the small **sync** button on top |
| Joy-Con | Hold the **sync** button on the rail (one Joy-Con at a time for now) |
| Wii Remote / Wii U Pro | Press the red **SYNC** button (battery cover / back) |
| Stadia | Must run the Bluetooth firmware; hold **Stadia + Y** until the light flashes |
| Xbox Wireless (BLE firmware, untested) | Hold the **pair** button on top until the logo flashes fast. Supported by Bluepad32 but not yet tracked in the support table |
| 8BitDo (SN30 Pro, Pro 2, ...) | Switch it on in a mode (below), then hold **Pair** for 3 s |

8BitDo pads pair separately in each mode, so pick one and stay with it:

| Power-on combo | Mode |
| --- | --- |
| **Start + Y** | Switch |
| **Start + B** | Android (D-Input) |
| **Start + X** | Windows (X-Input) |
| **Start + A** | macOS |

If a controller that was paired before refuses to connect, forget everything (hold **BOOT** 5 s) and pair again.
